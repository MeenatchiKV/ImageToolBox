# ImageToolBox
A web based application for commonly used image pre-processing tasks

Required Softwares:
1. XAMPP or other server
2. Python Flask

Steps to execute this web application.

1. Host the folder in any webserver. If running in localhost the link for the site would be "HTTP://localhost/ImageToolBox"
2. Install the required dependencies from "requirements.txt"
3. Start the flask app by running "python flask-app.py"
4. Go to the site provided by the server, "HTTP://localhost/ImageToolBox" and execute the pre-processing tasks.
